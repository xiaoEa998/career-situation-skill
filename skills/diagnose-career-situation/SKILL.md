# 弄清楚职业处境

帮助用户看清自己在行业、公司、部门和关系网络中的位置，区分真实能力、依赖条件与尚未验证的判断，并形成一个低风险的下一步行动。

## 选择工作模式

- 用户只描述了模糊困境时，进入“引导访谈”，一次只问一个关键问题。
- 用户已经提供较完整资料时，先整理证据，再只追问会改变结论的缺口。
- 用户明确要求完整报告时，在完成最低信息门槛后使用报告模板。
- 用户只想讨论一个具体事件时，先分析该事件，不强迫完成整套诊断。

需要访谈问题时，读取 [references/interview-guide.md](references/interview-guide.md)。
需要判断证据强弱、归因或风险时，读取 [references/evidence-and-reasoning.md](references/evidence-and-reasoning.md)。
需要交付完整诊断时，读取 [references/report-template.md](references/report-template.md)。
用户希望先填写资料时，提供或复制 [assets/intake-form.md](assets/intake-form.md)。

## 建立最低信息门槛

在给出确定性诊断前，至少弄清：

1. 当前行业、公司类型、岗位和工作年限；
2. 收入由什么组成，哪些稳定、哪些随结果变化；
3. 公司为什么为这个岗位付钱，希望获得什么结果；
4. 最近一次让用户感到卡住的具体事件；
5. 至少一个能证明用户创造过结果的案例；
6. 用户想改变什么，以及时间、资金和风险约束。

如果缺少其中任何会改变结论的信息，明确说“不足以判断”，然后一次追问一个最关键的问题。不要用常识替用户补齐公司事实。

## 执行诊断流程

### 1. 记录问题与事实

- 保留用户对核心困境的原话。
- 追问具体时间、动作、参与者、数字、结果和可核对证据。
- 给重要信息标记 F（事实）、I（推断）、H（假设）或 V（待验证）。
- 对金额允许使用区间，不索取客户姓名、账号密码或公司机密。

### 2. 绘制四张钱图

依次说明：

1. **行业的钱：** 最终谁付钱、为什么购买、钱经过哪些角色、哪些环节更有利润或议价权。
2. **公司的钱：** 公司卖什么、卖给谁、利润由什么驱动、当前最想增长或守住什么。
3. **部门的钱：** 部门承诺什么结果、争取什么预算和资源、真正瓶颈在哪里。
4. **关系人的钱：** 上司、关键同事、客户、供应商和平台分别追求什么、控制什么资源、与用户如何共同受益或冲突。

每张图都区分已知与未知。不要把用户对行业或公司的猜测写成事实。

### 3. 定位用户在系统中的位置

判断并说明：

- 用户创造收入、降低成本、提高效率、控制风险或改善体验中的哪一种结果；
- 哪些环节由用户直接控制，哪些依赖品牌、预算、同事、渠道或运气；
- 离开公司后能带走哪些能力、方法、案例、作品、声誉或合法关系；
- 哪些成果会随时间积累，哪些每月都要从零开始；
- AI更可能替代哪些标准动作，又可能放大哪些判断、关系和复合能力。

### 4. 提炼可交易能力

把能力写成“动作 + 对象 + 结果 + 证据”，不要只写“靠谱”“沟通能力强”等形容词。

同时写明归因限制。例如：获得客户可以证明获客能力，但没有复购和完整成本数据时，不能证明渠道已经盈利。

### 5. 找出核心矛盾

用一句话描述“用户想得到的结果”与“当前机制、证据或约束”之间的冲突。优先检查：

- 有能力，但缺少可携带证据；
- 有结果，但成果主要沉淀在公司；
- 有时间，但同时推进过多方向；
- 想改变收入，却不知道必要支出和安全垫；
- 想辞职、转岗或创业，但关键假设尚未测试。

不要使用“天生适合”“性格决定”等不可验证标签。

### 6. 比较现实路径

只比较用户现实存在的选项，例如留在当前岗位升级、换公司、转岗、副业或创业。对每条路径写明：

- 可能收益；
- 主要代价；
- 关键假设；
- 当前证据强度；
- 30天内最低成本的验证方法。

不要在缺少现金流、家庭责任和风险承受信息时建议辞职、借贷或大额投入。

### 7. 给出一个行动

优先提供一个7天行动，最多再给一个30天实验。每个行动都写明：

- 要做什么；
- 可观察的完成标准；
- 所需时间和成本上限；
- 要验证的假设；
- 何时停止或调整。

行动目标是获得新证据，不是用忙碌代替判断。

## 交付与用户核对

先给结论，再给依据。明确列出：

- 表层困境；
- 核心矛盾；
- 四张钱图；
- 可交易能力及证据；
- 关键未知；
- 暂时不能下的结论；
- 一个7天行动；
- 一个30天实验（如有必要）。

最后邀请用户指出最准确和最不准确的判断，并根据新事实就地修正。不要为了显得完整而保留已被推翻的结论。

## 保持边界

- 不把本流程描述为心理咨询、法律意见、投资建议或招聘承诺。
- 不保证升职、涨薪、成功转行或创业成功。
- 用户出现明显心理危机时，停止职业诊断并鼓励其寻求合适的专业支持。
- 涉及高风险决定时，提供证据边界和验证步骤，不替用户作最终决定。
