# 首轮访谈提纲

建议用时：30—60分钟。一次只问一个问题，先收集事实，再解释和建议。

## 开场

说明：

> 这不是性格测试，也不会直接替你决定辞职或转行。我们会根据真实工作事件，看清行业、公司、部门和关键关系人的利益，再判断你积累了什么、缺什么证据，以及下一步最值得验证什么。你不需要透露公司机密，金额可以使用区间。

确认用户是否愿意：

- 提供具体工作案例；
- 匿名记录文字信息；
- 在7天后检查是否执行约定行动。

## 第一层：当前处境

1. 你现在的行业、公司类型、岗位和工作年限分别是什么？
2. 收入由哪些部分组成？哪些稳定，哪些随结果变化？
3. 一周主要做哪些工作？大致各占多少时间？
4. 公司为什么愿意为你的岗位付钱？希望你带来什么结果？
5. 现在最难受、最想改变的具体处境是什么？
6. 最近一次让你明显感到卡住的事件是什么？
7. 如果一年不改变，会造成什么现实后果？

对具体事件追问：发生时间、涉及角色、用户动作、结果、用户的解释和可核对证据。

## 第二层：四张钱图

### 行业

1. 最终是谁为产品或服务付钱？为什么买？
2. 从最终付费者到公司，中间有哪些角色？
3. 哪些环节更赚钱或更有议价权？依据是什么？
4. 最近的技术、政策、渠道或供需变化正在让谁受益、让谁变难？
5. 哪些判断是亲历事实，哪些只是听说？

### 公司

1. 公司主要卖什么、卖给谁？收入大头来自哪里？
2. 客户为什么选择公司：价格、品牌、渠道、技术、交付、关系还是其他？
3. 公司最重要的成本和风险是什么？
4. 公司当前最想增长、守住或摆脱什么？
5. 用户的工作影响收入、成本、效率、风险或回款中的哪一项？
6. 如果停止该岗位三个月，公司可能损失什么？

### 部门

1. 部门对公司承诺什么结果？
2. 是否有明确目标、期限和考核口径？
3. 部门拥有什么预算、人员、授权和老板耐心？
4. 真正瓶颈在获客、转化、产品、交付、协作还是资源？
5. 部门如何证明自己值得继续获得资源？
6. 用户能控制和不能控制的环节分别是什么？

### 关系人

围绕上司、关键同事、客户、供应商和平台分别问：

1. 对方最想得到什么结果？
2. 对方的收益、评价或安全感由什么决定？
3. 对方控制着什么关键资源？
4. 双方是共同受益、相互依赖，还是存在成果分配冲突？
5. 用户为对方创造什么价值，对方为什么愿意配合？

## 第三层：个人价值与积累

1. 过去三年，哪三件事最能证明你创造过结果？
2. 每件事的背景、投入、动作和结果是什么？
3. 有数据、作品或第三方可以验证吗？
4. 哪些结果由本人直接控制，哪些依赖团队、品牌、预算或运气？
5. 离开公司后，可以带走哪些能力、案例、方法、作品、声誉或合法关系？
6. 哪些事情会随时间积累？哪些每月都要从零开始？
7. 别人现在已经为什么向你付钱？哪些只是你推测别人会付钱？
8. AI更可能替代哪些动作，又可能放大哪些判断或资源？

## 第四层：目标、代价与选择

1. 未来三年最优先想获得什么可量化结果？
2. 这个结果解决什么现实问题？
3. 愿意和不愿意放弃什么？
4. 每周能稳定投入多少时间和资金？
5. 能承受多久没有回报？月均必要支出和安全垫是多少？
6. 现实选项有哪些？
7. 哪个选项可以用最低成本在30天内获得最关键的新证据？

## 结束核对

先复述：

> 已确认的事实是……  
> 根据事实做出的推断是……  
> 尚无证据的假设是……  
> 最值得先验证的是……

再问：

1. 哪条最准确？
2. 哪条不准确或遗漏背景？
3. 今天是否看见了此前没有看见的利益关系？
4. 愿意在7天内完成什么行动？
5. 完整诊断中哪一部分真正值得付费？为什么？
